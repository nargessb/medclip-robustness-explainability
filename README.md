# Robustness of Explainability Maps in Medical Vision-Language Models (MedCLIP)

Can a small, near-invisible perturbation to a chest X-ray change *where* a medical vision-language model says it is looking? This project studies the adversarial robustness of **patch-level explanation (similarity) maps** in [MedCLIP](https://github.com/RyanWangZf/MedCLIP), a CLIP-style model pretrained on chest radiographs and radiology reports. It also tests whether **CLIP Surgery**-style feature surgery recovers faithful explanations under attack.

In clinical settings, saliency/similarity maps are often what a radiologist uses to decide whether to trust a model's finding. If those maps can be redirected by an imperceptible perturbation, the explanation itself becomes an attack surface.

## What this repo does

1. **Zero-shot MedCLIP on chest X-rays**: encodes an X-ray and a set of radiology findings (e.g. *pleural effusion*, *pneumothorax*, *chronic rib deformity*) with MedCLIP's Swin-T image encoder and Bio_ClinicalBERT text encoder.
2. **Adversarial attack**: gradient-based perturbation (SGD on the input, clamped to the valid pixel range) that suppresses the image-text similarity of a chosen finding.
3. **Explanation maps**: patch-token × text-embedding similarity maps, with and without *feature surgery* (mean-centering patch features to remove redundant, class-agnostic activation).
4. **Comparison**: clean vs. adversarial and surgery vs. no-surgery heatmaps, the perturbation itself (×50), and the zero-shot scores before and after the attack.

## Repository layout

```
run_medclip_attack.py      # main, reproducible experiment (saves all figures + scores.csv)
attacks/                   # research scripts developed along the way
  medclip_surgery_attack*.py   # MedCLIP attack + surgery iterations
  medclip_targeted_attack.py   # targeted variant
  clip_surgery_demo.py, clip_attack_with_heat.py, clip_advanced_attack.py,
  demo_attacked.py, working_demo.py   # CLIP (natural-image) baseline experiments
medclip/                   # MedCLIP package (Wang et al., 2022) with additions:
  medclip_surgery_model.py     # MedCLIP-Surgery wrapper  (new)
  build_model.py               # builds MedCLIP-Surgery from a MedCLIP state dict  (new)
  modeling_medclip.py, vision_model.py  # modified to return patch tokens
assets/medclip_prompts.txt # radiology prompt list
results/
  clip_natural_image/      # baseline: the same pipeline on CLIP with a natural image
  medclip_xray/            # MedCLIP chest X-ray results (generated by run_medclip_attack.py)
```

## Running it

```bash
pip install -r requirements.txt
python run_medclip_attack.py --image path/to/chest_xray.jpg \
    --target "chronic rib deformity" \
    --attack-class "no acute cardiopulmonary process"
```

MedCLIP's pretrained weights and the Hugging Face encoders download on first run. A GPU is recommended but not required for a single image. Use only de-identified, publicly shareable X-rays if you plan to commit outputs. Datasets such as MIMIC-CXR do not allow redistributing their images.

### Baseline: CLIP on a natural image

Before moving to the medical model, the same attack-and-surgery pipeline was validated on OpenAI CLIP (ViT-B/16) with CLIP Surgery on a natural image. 

What this shows: the attack scatters the raw similarity map for the attacked class, and feature surgery does not fully recover it. For a non-attacked class ("person"), surgery largely restores a faithful map. All 13 figures are in `results/clip_natural_image/`.

## Notes and limitations

- The experiments are per-image case studies, not a dataset-level benchmark. Quantitative evaluation over a held-out X-ray set (e.g. pointing-game or IoU against expert annotations) is the natural next step.
- The step size of 0.01 × 10 steps is not norm-bounded the way PGD is, so perturbations can be visible (see the ×50 panel). An ε-bounded PGD variant would give a stricter threat model.
- `build_model.py` loads weights with `strict=False`, and MedCLIP's vision keys (`vision_model.*`) don't match MedCLIP-Surgery's (`visual.*`). `run_medclip_attack.py` therefore loads the MedCLIP vision weights into the surgery branch explicitly.
